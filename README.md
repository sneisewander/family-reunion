# Raynor Family Reunion Website

## About

This repo contains the source code for a shareholder convention / family reunion hosted by [Raynor Garage Doors](https://raynor.com). The site is intended for use by Raynor shareholders and family members only.

## Specs

The site is (almost) [Material 3](https://m3.material.io/) compliant, and is written using [HTML](https://developer.mozilla.org/en-US/docs/Web/HTML), [CSS](https://developer.mozilla.org/en-US/docs/Web/CSS), and [JS](https://developer.mozilla.org/en-US/docs/Web/JavaScript), and [JQuery](https://jquery.com/). If I had to recreate the site again, I would have done it with [React](https://react.dev) + [Tailwind](https://tailwindcss.com/) + [Typescript](https://typescriptlang.org/), but I wanted to develop a solid foundation on simple tools before learning a more robust framework. Hosted on [Firebase](https://firebase.google.com).
